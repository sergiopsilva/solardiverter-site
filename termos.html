5. Aquisição de Licenças PRO

5.1 Processo de Aquisição

  1. Utilizador fornece o Chip ID do ESP32 através do formulário de contacto
  2. AlternativaIOT fornece informações de pagamento
  3. Após confirmação de pagamento, a chave de ativação é gerada
  4. Chave enviada por email no prazo de 48 horas úteis
  5. Utilizador insere a chave na interface web do dispositivo

5.2 Pagamento

  • Pagamento único (não há subscrições recorrentes)
  • Métodos de pagamento: Transferência bancária, PayPal ou outros acordados
  • Preços apresentados incluem IVA quando aplicável

5.3 Chave de Ativação

A chave PRO é:

  • Gerada com base no Chip ID específico do ESP32
  • Válida apenas para esse dispositivo
  • Não transferível para outro ESP32
  • Permanente (não expira)
  • Não reembolsável após envio
