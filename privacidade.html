Política de Privacidade

Última atualização: 5 de maio de 2026

1. Introdução

A sua privacidade é importante para nós. Esta Política de Privacidade explica como o SolarDiverter (operado por AlternativaIOT) recolhe, utiliza e protege os seus dados pessoais quando utiliza o nosso website e serviços.

Ao utilizar o nosso website e submeter o formulário de contacto, concorda com as práticas descritas nesta política.

3. Dados Que Recolhemos

3.1 Formulário de Contacto

Quando utiliza o formulário de contacto no nosso website, recolhemos:

  • Nome: Para identificação e comunicação personalizada
  • Email: Para responder ao seu pedido
  • Mensagem: Conteúdo do seu pedido ou questão
  • Chip ID (opcional): Se solicitar ativação de licença

3.2 Dados Técnicos Automáticos

Não utilizamos cookies de rastreamento. Apenas dados técnicos básicos fornecidos pelo servidor de alojamento (GitHub Pages):

  • Endereço IP (logs do servidor, retidos por GitHub)
  • Tipo de navegador e sistema operativo
  • Data e hora de acesso

Nota: Este website é alojado no GitHub Pages. Consulte a Política de Privacidade do GitHub para informações sobre como o GitHub processa dados técnicos.

4. Finalidade do Tratamento

Utilizamos os seus dados pessoais apenas para:

  • Responder aos seus pedidos: Ativações LITE, pedidos PRO, suporte técnico
  • Geração de chaves de ativação: Baseadas no Chip ID fornecido
  • Comunicação relacionada com o serviço: Envio de chaves, esclarecimentos
  • Cumprimento de obrigações legais: Se aplicável

Não utilizamos os seus dados para:

  • Marketing não solicitado
  • Partilha com terceiros para fins comerciais
  • Criação de perfis de utilizador

5. Base Legal para o Tratamento (RGPD)

Processamos os seus dados com base em:

  • Consentimento (Art. 6(1)(a) RGPD): Ao submeter o formulário, consente o tratamento dos dados fornecidos
  • Execução de contrato (Art. 6(1)(b) RGPD): Processamento de ativações e licenças PRO adquiridas
  • Interesses legítimos (Art. 6(1)(f) RGPD): Resposta a pedidos de suporte técnico

6. Partilha de Dados com Terceiros

Não vendemos, alugamos ou partilhamos os seus dados pessoais com terceiros, exceto nas seguintes situações:

  • Prestadores de serviço essenciais: GitHub Pages (alojamento), serviços de email (para resposta aos pedidos)
  • Obrigações legais: Se exigido por lei, ordem judicial ou autoridades competentes

7. Retenção de Dados

Retemos os seus dados pessoais apenas pelo tempo necessário:

  • Pedidos de ativação LITE: 2 anos após envio da chave
  • Licenças PRO adquiridas: Durante a validade da licença + 3 anos (obrigações fiscais)
  • Pedidos de suporte não concluídos: 1 ano

Após estes períodos, os dados são eliminados de forma segura.

8. Os Seus Direitos (RGPD)

Nos termos do Regulamento Geral de Proteção de Dados (RGPD), tem os seguintes direitos:

  • Direito de acesso (Art. 15): Pode solicitar cópia dos dados que detemos sobre si
  • Direito de retificação (Art. 16): Pode solicitar correção de dados incorretos
  • Direito ao apagamento (Art. 17): Pode solicitar eliminação dos seus dados ("direito a ser esquecido")
  • Direito à limitação (Art. 18): Pode solicitar restrição do tratamento
  • Direito à portabilidade (Art. 20): Pode solicitar os seus dados em formato estruturado
  • Direito de oposição (Art. 21): Pode opor-se ao tratamento dos seus dados

Para exercer qualquer destes direitos, contacte-nos através do formulário do website com o assunto "RGPD - [tipo de pedido]".

Prazo de resposta: Responderemos ao seu pedido no prazo de 30 dias, conforme exigido pelo RGPD.

9. Segurança dos Dados

Implementamos medidas de segurança técnicas e organizacionais apropriadas:

  • Comunicação segura: HTTPS em todo o website
  • Proteção anti-spam: Verificação matemática no formulário (sem reCAPTCHA de terceiros)
  • Armazenamento limitado: Dados mantidos apenas pelo tempo necessário
  • Acesso restrito: Apenas o responsável tem acesso aos dados recolhidos

No entanto, nenhum método de transmissão pela Internet é 100% seguro. Enviamos dados sensíveis (chaves de ativação) por email — considere a segurança da sua conta de email.

10. Transferências Internacionais

Os seus dados podem ser armazenados em servidores localizados fora da União Europeia (GitHub Pages, serviços de email). Nestas situações, garantimos que são aplicadas salvaguardas adequadas conforme exigido pelo RGPD.

11. Cookies

Este website NÃO utiliza cookies de rastreamento ou analytics.

Não utilizamos Google Analytics, Facebook Pixel ou qualquer tecnologia de rastreamento de terceiros.

12. Menores de Idade

Os nossos serviços não se destinam a menores de 18 anos. Não recolhemos intencionalmente dados de menores. Se tiver conhecimento de que um menor forneceu dados pessoais, contacte-nos para remoção imediata.

13. Alterações a Esta Política

Podemos atualizar esta Política de Privacidade periodicamente. A data de "Última atualização" no topo indica a versão mais recente. Alterações significativas serão comunicadas no website.
